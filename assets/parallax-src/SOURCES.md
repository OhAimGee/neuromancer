# Sources des plans de parallaxe

Ces PNG sont les **originaux RGB**, tels que livrés par leur auteur. Ils ne sont pas servis au
jeu : `tools/aseprite/etalonner.lua` les étalonne en nuit et les quantifie sur la palette 32
couleurs du projet, puis écrit le résultat dans `public/assets/parallax/`.

On garde les originaux ici pour pouvoir refaire l'étalonnage sans retélécharger quoi que ce
soit — les réglages de `data/etalonnage.json` sont faits pour être repris.

| Fichier | Origine |
|---|---|
| `rue_fond` `rue_milieu` `rue_avant` | *Cyberpunk Street Environment*, Version 2 / Layers |
| `ciel_fond` `ciel_tours` `ciel_avant` | *Cyberpunk Street Environment*, city skyline / Layers |
| `port_fond` `port_milieu` `port_avant` | *Cyberpunk Street Environment*, Version 1 / PNG / layers |
